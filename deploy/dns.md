# DNS 解析（域名服务商后台）

把域名 `huimei-ceramic.ltd` 解析到服务器 `43.142.19.45`：

| 类型 | 主机记录 | 记录值 | 说明 |
|------|----------|--------|------|
| A | `@` | `43.142.19.45` | 主域名 |
| A | `www` | `43.142.19.45` | www 子域名 |

TTL 可先设 600 秒。生效后：

```bash
ping huimei-ceramic.ltd
# 应解析到 43.142.19.45
```

云服务器安全组 / 防火墙需放行 **TCP 80、443**。
